# Estabilização premium — 17/09/2026

Este lote consolida melhorias de confiabilidade e leitura sem alterar a identidade visual aprovada.

## Incluído

- API administrativa para consulta de auditoria.
- Registro de criação, alteração e redefinição de senha de usuários sem armazenar senhas.
- Auditoria do estado operacional já ativa no Supabase.
- Índice de auditoria por data para consultas recentes.
- Checklist de QA responsivo em cinco viewports.
- Camada de legibilidade mobile para KPIs, clientes, dock e PDV.
- Verificação de integridade atualizada para falhar o build se a camada de legibilidade desaparecer.

## Fora deste lote

- Ativação de proteção contra senhas vazadas no painel do Supabase Auth.
- Migração de `app_state` para as tabelas normalizadas.
- Redesign estrutural do frontend.
